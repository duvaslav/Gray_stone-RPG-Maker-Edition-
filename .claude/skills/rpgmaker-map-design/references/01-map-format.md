# Формат данных карты (MV и MZ)

MV и MZ хранят карты одинаково. Всё, что ниже, сверено с корескриптом
`rmmz_core.js` / `rmmz_objects.js` (у MV — `rpg_core.js` / `rpg_objects.js`,
логика та же).

## Файлы

| Файл | Что внутри |
|---|---|
| `data/MapXXX.json` | одна карта (`Map001.json` = карта 1, номер с ведущими нулями до 3 знаков) |
| `data/MapInfos.json` | дерево карт в редакторе: имя, родитель, порядок |
| `data/Tilesets.json` | тайлсеты: имена листов + массив флагов на 8192 тайла |
| `img/tilesets/*.png` | сами листы |
| `img/characters/*.png` | спрайты для событий |

Редактор пишет JSON **одной строкой без отступов**. Пиши так же
(`JSON.stringify(obj)` без третьего аргумента), иначе редактор переформатирует
файл при первом сохранении и получится мусорный diff.

## MapXXX.json

```jsonc
{
  "autoplayBgm": false, "bgm": {"name":"","pan":0,"pitch":100,"volume":90},
  "autoplayBgs": false, "bgs": {"name":"","pan":0,"pitch":100,"volume":90},
  "battleback1Name": "", "battleback2Name": "", "specifyBattleback": false,
  "disableDashing": false,          // запрет бега — включай в тесных интерьерах
  "displayName": "",                // подпись, всплывающая при входе
  "encounterList": [], "encounterStep": 30,
  "height": 13, "width": 17,
  "note": "",                       // читается плагинами: <тег: значение>
  "parallaxName": "", "parallaxLoopX": false, "parallaxLoopY": false,
  "parallaxShow": true, "parallaxSx": 0, "parallaxSy": 0,
  "scrollType": 0,                  // 0 нет, 1 по горизонтали, 2 по вертикали, 3 обе
  "tilesetId": 1,
  "data": [ ... ],                  // width * height * 6 целых чисел
  "events": [null, {...}, {...}]    // индекс = id события, нулевой всегда null
}
```

### Массив `data`

Длина строго `width * height * 6`. Индексация — как в `Game_Map.tileId`:

```js
index = (z * height + y) * width + x
```

| z | Слой | Что кладут |
|---|---|---|
| 0 | нижний | земля, пол, вода, стены — «основа», по ней считается проходимость |
| 1 | нижний 2 | ковры, дорожки, крупная мебель, наложенный декор |
| 2 | верхний | то, что должно быть над героем при флаге ★, кроны, верхушки |
| 3 | верхний 2 | ещё один слой того же назначения |
| 4 | тени | битовая маска четвертей: 1 = ↖, 2 = ↗, 4 = ↙, 8 = ↘ |
| 5 | регионы | id региона 0..255, рисуется «кистью регионов» |

Слои 0–3 — это ровно то, что в редакторе переключается клавишами слоёв.
Движок при отрисовке кладёт z0 и z1 «под героя», затем тень, затем z2 и z3;
любой тайл с флагом ★ уходит в верхний слой независимо от z.

**Регионы** сами по себе ничего не делают — это метки для событий и плагинов
(`$gameMap.regionId(x,y)`, условие «Получить данные местности»). Типичное
применение: зоны случайных встреч, запрет ставить мебель, точки спавна NPC,
границы для патрулей.

**Тени** — тот самый «карандаш тени» в редакторе. Значение 5 (`0b0101`) —
затемнены обе левые четверти, это стандартная тень справа от вертикальной
грани стены.

## Событие

```jsonc
{
  "id": 1, "name": "Свеча", "note": "",
  "x": 5, "y": 3,
  "pages": [ { ... } ]
}
```

`events[0]` всегда `null`, а `events[i].id` обязан совпадать с `i`.

### Страница события

```jsonc
{
  "conditions": {
    "actorId": 1,       "actorValid": false,
    "itemId": 1,        "itemValid": false,
    "selfSwitchCh": "A","selfSwitchValid": false,
    "switch1Id": 1,     "switch1Valid": false,
    "switch2Id": 1,     "switch2Valid": false,
    "variableId": 1,    "variableValid": false, "variableValue": 0
  },
  "image": { "tileId": 0, "characterName": "", "characterIndex": 0,
             "direction": 2, "pattern": 1 },
  "directionFix": false, "walkAnime": true, "stepAnime": false, "through": false,
  "moveType": 0, "moveSpeed": 3, "moveFrequency": 3,
  "moveRoute": { "list": [{"code":0,"parameters":[]}],
                 "repeat": true, "skippable": false, "wait": false },
  "priorityType": 0,
  "trigger": 0,
  "list": [ {"code":101,"indent":0,"parameters":[...]}, {"code":0,"indent":0,"parameters":[]} ]
}
```

Ключевые поля:

- **`trigger`**: `0` кнопка действия, `1` касание игроком, `2` касание событием,
  `3` автозапуск (блокирует управление!), `4` параллельный процесс.
- **`priorityType`**: `0` под героем (ковры, лужи), `1` вровень — событие
  **блокирует проход** (сундук, NPC), `2` над героем (кроны, арки).
- **`image.tileId`**: если > 0, событие рисуется тайлом из листов B–E, а не
  спрайтом персонажа. Это главный приём для «интерактивной мебели».
- **`list`** обязан заканчиваться командой `{"code":0}`.

**Выбор страницы**: движок берёт **последнюю** страницу, все условия которой
выполнены (`Game_Event.findProperPageIndex` идёт с конца). Поэтому «выключённое»
состояние кладут первой страницей, «включённое» — второй.

**Собственные переключатели** (`A`–`D`) живут внутри одного события и хранятся
по ключу `[mapId, eventId, ch]`. Снаружи их штатно не переключить — соседнее
событие своим переключателем не поуправляет.

## MapInfos.json

```jsonc
[null, {"id":1,"name":"Таверна","parentId":0,"order":1,
        "expanded":false,"scrollX":0,"scrollY":0}]
```

Карта, которой нет в `MapInfos.json`, не появится в дереве редактора, даже если
файл `MapXXX.json` лежит на месте. Создавая карту скриптом, регистрируй её:
`project.registerMap(id, name, {parentId})`.

## Tilesets.json

```jsonc
{ "id": 1, "name": "Интерьер", "mode": 1, "note": "",
  "tilesetNames": ["Inside_A1","Inside_A2","","Inside_A4","Inside_A5",
                   "Inside_B","Inside_C","",""],
  "flags": [ /* 8192 чисел, индекс = tileId */ ] }
```

- `tilesetNames` — ровно 9 имён в порядке **A1, A2, A3, A4, A5, B, C, D, E**
  (без расширения, файлы ищутся в `img/tilesets/`). Пустая строка — лист не задан.
- `mode`: `0` — тип «мир» (`Game_Map.isOverworld()`, влияет на транспорт и
  отображение автотайлов мирового масштаба), `1` — обычная область.
- `flags` — см. `02-tile-ids.md`.

## Что ломается чаще всего

1. **Длина `data` не равна `w*h*6`** — карта не откроется. Меняя размер, пересобирай массив.
2. **`events[i].id !== i`** — редактор запутается в нумерации.
3. **Список команд без `{"code":0}` в конце** — интерпретатор уйдёт за границу массива.
4. **Карта не зарегистрирована в MapInfos.json** — её просто не видно.
5. **Красивый JSON с отступами** — не ошибка, но редактор всё перепишет.
