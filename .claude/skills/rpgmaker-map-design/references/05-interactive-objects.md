# Интерактивные объекты: мебель, которая ведёт себя как объект

Ключевая идея: **в RPG Maker нет «объектов», есть события, притворяющиеся
объектами**. Свеча, сундук, дверь, рычаг — это события, у которых картинка
взята не из спрайтов персонажей, а прямо из тайлсета.

## Базовый приём: событие с картинкой-тайлом

У страницы события есть `image.tileId`. Если он больше нуля, движок рисует
не спрайт, а тайл из листов B–E — тот же самый, что лежал бы на карте:

```js
Ev.page({
  image: Ev.tileImage(T.b(5, 0)),  // тайл (col 5, row 0) листа B
  trigger: 0,                      // кнопка действия
  priority: 0,                     // под героем
  directionFix: true,              // не поворачивается к игроку
  walkAnime: false,                // не «шагает» на месте
  list: [...Cmd.text(["Обычная свеча."])],
});
```

`directionFix: true` и `walkAnime: false` обязательны почти всегда: без них
«свеча» будет разворачиваться к игроку, как живой NPC.

Выбор `priority`:

| Значение | Поведение | Для чего |
|---|---|---|
| 0 | под героем | ковёр, лужа, светящийся круг, свеча на столе |
| 1 | вровень — **блокирует проход** | сундук, бочка, NPC, рычаг |
| 2 | над героем | крона, арка, свисающая ткань |

## Свеча, которую можно зажечь и потушить

Классика на **двух страницах и одном собственном переключателе**. Движок берёт
последнюю страницу, чьи условия выполнены, поэтому:

- **страница 1** — без условий: свеча погашена;
- **страница 2** — условие «собственный переключатель A»: свеча горит.

```js
const off = Ev.page({
  image: Ev.tileImage(B.candleOff),
  trigger: 0, priority: 0, directionFix: true, walkAnime: false,
  list: [
    ...Cmd.text(["Свеча погасла. Зажечь её?"]),
    ...Cmd.choices(["Зажечь", "Оставить"], { cancelType: 1 }),
    ...Cmd.when(0, "Зажечь"),
    ...indent([...Cmd.playSE("Fire"), ...Cmd.selfSwitch("A", true)]),
    ...Cmd.when(1, "Оставить"),
    ...indent([]),
    ...Cmd.endBranch(),
  ],
});

const on = Ev.page({
  conditions: { selfSwitch: "A" },
  image: Ev.tileImage(B.candleOn),
  trigger: 0, priority: 0, directionFix: true, walkAnime: false,
  stepAnime: true,                       // если картинка анимированная — оживёт
  list: [
    ...Cmd.text(["Пламя ровно горит."]),
    ...Cmd.choices(["Потушить", "Оставить"], { cancelType: 1 }),
    ...Cmd.when(0, "Потушить"),
    ...indent([...Cmd.playSE("Wind7"), ...Cmd.selfSwitch("A", false)]),
    ...Cmd.when(1, "Оставить"),
    ...indent([]),
    ...Cmd.endBranch(),
  ],
});

map.addEvent(Ev.event({ name: "Свеча", x: 5, y: 3, pages: [off, on] }));
```

Полный рабочий вариант — `scripts/examples/tavern-room.js`.

**Если огонёк должен мерцать**, картинку удобнее брать из `img/characters/`
(спрайт из 3 кадров) и включить `stepAnime: true`: тайл из тайлсета не
анимируется, а спрайт персонажа — да.

### Границы собственных переключателей

Собственный переключатель хранится по ключу `[mapId, eventId, "A"..."D"]` и
**не виден снаружи события**. Поэтому:

- «зажечь все свечи в зале разом» одним собственным переключателем не сделать —
  нужен **глобальный переключатель** (условие `switch1`) или плагин;
- удобный гибрид: третья страница с условием глобального переключателя
  «в зале зажгли свет» — тогда рычаг у входа переключает весь зал, а каждая
  свеча по-прежнему щёлкается отдельно.

## Сундук, открывающийся один раз

```js
const closed = Ev.page({
  image: Ev.tileImage(B.chestClosed),
  trigger: 0, priority: 1, directionFix: true, walkAnime: false,
  list: [
    ...Cmd.playSE("Chest"),
    ...Cmd.changeItems(1, 1),
    ...Cmd.text(["\\}Найдено: \\i[1] ×1\\{"]),
    ...Cmd.selfSwitch("A", true),
  ],
});
const opened = Ev.page({
  conditions: { selfSwitch: "A" },
  image: Ev.tileImage(B.chestOpen),
  trigger: 0, priority: 1, directionFix: true, walkAnime: false,
  list: [...Cmd.text(["Пусто."])],
});
```

`priority: 1` обязателен: иначе игрок встанет внутрь сундука.

## Дверь

```js
Ev.page({
  image: Ev.tileImage(B.doorBottom),
  trigger: 1,          // касание игроком: не нужно жать кнопку
  priority: 1,
  directionFix: true, walkAnime: false,
  list: [
    ...Cmd.playSE("Open1"),
    ...Cmd.wait(20),
    ...Cmd.transfer(2, 8, 3, 2, 0),   // карта 2, (8,3), лицом вниз
  ],
});
```

Двери-«картинки» с анимацией открытия делаются маршрутом движения с
переключением кадров спрайта двери, но для 90 % случаев хватает звука и паузы.

Проверь у себя: координаты назначения ведут **на проходимую клетку** и герой
после перехода смотрит внутрь помещения, а не в стену.

## Осматриваемая мебель (самое выгодное вложение)

Событие вообще без картинки: тайл уже нарисован на карте, событие только
ловит нажатие.

```js
Ev.page({
  image: Ev.tileImage(0),      // картинки нет
  trigger: 0, priority: 1,     // 1, если предмет должен ещё и загораживать
  directionFix: true, walkAnime: false,
  list: [...Cmd.text([
    "Потрёпанные книги о торговых путях.",
    "Между страниц кто-то оставил засушенный цветок.",
  ])],
});
```

Одна такая заготовка тиражируется на полки, картины, окна, посуду, бочки.
2–5 штук на комнату — и мир перестаёт быть немым.

## Прилавок: разговор через стойку

Не событие, а **флаг тайла**: `0x80` (counter). Игрок может активировать
событие, стоящее **за** тайлом с этим флагом. Ставится на стойки лавок,
барные стойки, окошки касс. У A2 тот же бит дополнительно включает режим
«стол» (свисающая кромка).

## Скрытый проход и переключаемые декорации

- **Шкаф, который отодвигается**: страница 1 — шкаф (priority 1, картинка-тайл),
  при активации ставит собственный переключатель A; страница 2 (условие A) —
  картинки нет, `through: true`, проход открыт. Тайл прохода при этом должен
  быть заранее нарисован на карте под шкафом.
- **Мост/лестница появляется после события**: событие с условием глобального
  переключателя и картинкой-тайлом моста, `priority: 0`.
- **Ставни, факелы, рычаги** — та же двухстраничная схема, что у свечи.

## Триггеры: что когда использовать

| trigger | Когда срабатывает | Типичное применение |
|---|---|---|
| 0 | игрок нажал кнопку лицом к событию | осмотр, диалог, сундук, свеча |
| 1 | игрок наступил / упёрся | дверь, ловушка, переход |
| 2 | событие столкнулось с игроком | враг, преследователь |
| 3 | автозапуск — **блокирует управление** | катсцена; обязательно снимать себя переключателем |
| 4 | параллельный процесс | фоновая логика, анимация, таймер |

**Осторожно с 3 и 4**: страница с автозапуском, которая не выключает сама себя
(собственным или глобальным переключателем), намертво вешает игру. Параллельный
процесс без пауз ест кадры — на карте их должно быть единицы.

## Проверки

`map.validate()` ловит:

- события за границами карты и с `id`, не совпадающим с индексом;
- два события в одной клетке;
- страницы без команд и списки без завершающего `{"code":0}`;
- события, к которым **нельзя подойти** (со всех сторон непроходимо);
- декор, случайно сделавший стену проходимой.

Что валидатор не проверит и надо смотреть самому: тексты, номера предметов,
координаты переходов и то, что картинка-тайл действительно та, что задумана.
