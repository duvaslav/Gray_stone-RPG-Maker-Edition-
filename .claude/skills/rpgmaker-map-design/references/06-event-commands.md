# Коды команд событий

Список команд страницы — массив `{code, indent, parameters}`. Ниже — коды,
которые реально нужны при работе с картами; параметры сверены с
`Game_Interpreter` в корескрипте. Последней командой списка всегда идёт
`{"code":0,"indent":0,"parameters":[]}`.

`indent` — уровень вложенности внутри условных веток; движок им не управляет
поведением, но редактор отрисует кашу, если отступы не совпадут со скобками.

## Сообщения

| code | Команда | parameters |
|---|---|---|
| 101 | Показать сообщение (шапка) | `[faceName, faceIndex, background, positionType, speakerName]` |
| 401 | Строка текста | `[text]` — идут подряд сразу после 101 |
| 102 | Показать выбор | `[[варианты], cancelType, defaultType, positionType, background]` |
| 402 | Ветка «Когда \<вариант\>» | `[index, "текст"]` |
| 403 | Ветка «Когда отмена» | `[]` |
| 103 | Ввод числа | `[variableId, digits]` |
| 104 | Выбор предмета | `[variableId, itemType]` |
| 105 | Прокручиваемый текст | `[speed, noFast]` |
| 108 | Комментарий | `[text]` |

`background`: 0 окно, 1 затемнение, 2 прозрачно.
`positionType`: 0 сверху, 1 по центру, 2 снизу.

**Отличие MV/MZ**: пятый параметр 101 (`speakerName`, имя говорящего) есть
только в MZ. В MV он лишний и просто игнорируется, так что писать его безопасно.

## Логика

| code | Команда | parameters |
|---|---|---|
| 111 | Условная ветка | см. ниже |
| 411 | Иначе | `[]` |
| 412 | Конец ветки | `[]` |
| 112 / 413 | Цикл / Повторить | `[]` |
| 113 | Прервать цикл | `[]` |
| 115 | Прервать обработку события | `[]` |
| 117 | Вызвать общее событие | `[commonEventId]` |
| 118 / 119 | Метка / Переход к метке | `[name]` |

Параметры 111 по типу условия (`params[0]`):

- `0` переключатель: `[0, switchId, 0=ВКЛ|1=ВЫКЛ]`
- `1` переменная: `[1, variableId, 0=константа|1=переменная, значение, оператор]`
  (оператор: 0 `=`, 1 `≥`, 2 `≤`, 3 `>`, 4 `<`, 5 `≠`)
- `2` **собственный переключатель**: `[2, "A".."D", 0=ВКЛ|1=ВЫКЛ]`
- `8` предмет в инвентаре: `[8, itemId]`
- `12` скрипт: `[12, "js-выражение"]`

## Переключатели, переменные, инвентарь

| code | Команда | parameters |
|---|---|---|
| 121 | Управление переключателями | `[startId, endId, 0=ВКЛ\|1=ВЫКЛ]` |
| 122 | Управление переменными | `[startId, endId, операция, тип операнда, значение]` |
| 123 | Собственный переключатель | `["A".."D", 0=ВКЛ\|1=ВЫКЛ]` |
| 124 | Таймер | `[0=старт\|1=стоп, секунды]` |
| 125 | Изменить золото | `[0=+\|1=−, тип операнда, значение]` |
| 126 | Изменить предметы | `[itemId, 0=+\|1=−, тип операнда, количество]` |
| 127 / 128 | Изменить оружие / броню | `[id, 0=+\|1=−, тип, кол-во, включая экипировку]` |

Тип операнда: 0 — константа, 1 — значение переменной.

## Перемещение и персонажи

| code | Команда | parameters |
|---|---|---|
| 201 | Переместить игрока | `[0=прямо\|1=переменные, mapId, x, y, направление, тип затемнения]` |
| 203 | Задать позицию события | `[eventId, 0=прямо, x, y, направление]` |
| 205 | Задать маршрут движения | `[characterId, {list, repeat, skippable, wait}]` |
| 505 | Шаг маршрута (служебная) | `[{code, parameters}]` — дублирует шаги из 205 |
| 212 | Показать анимацию | `[eventId, animationId, ждать]` |
| 213 | Показать эмоцию | `[eventId, balloonId, ждать]` |
| 214 | Временно стереть событие | `[]` |

`characterId`: `-1` игрок, `0` это событие, `>0` id события.
Направление в 201: `0` не менять, `2` вниз, `4` влево, `6` вправо, `8` вверх.
Тип затемнения: `0` чёрное, `1` белое, `2` без затемнения.

**205 и 505 идут парой**: сам маршрут лежит в параметрах 205, а редактор
дополнительно выписывает каждый шаг отдельной строкой 505. Интерпретатор 505
пропускает, но без них редактор покажет пустой маршрут. `Cmd.moveRoute()`
формирует обе части.

## Экран и звук

| code | Команда | parameters |
|---|---|---|
| 221 / 222 | Затемнить / Осветлить экран | `[]` |
| 223 | Изменить оттенок экрана | `[[r,g,b,серый], длительность, ждать]` |
| 224 | Вспышка экрана | `[[r,g,b,сила], длительность, ждать]` |
| 225 | Тряска экрана | `[сила, скорость, длительность, ждать]` |
| 230 | Ждать | `[кадров]` (60 кадров = 1 секунда) |
| 231 / 232 / 235 | Показать / двигать / стереть картинку | см. корескрипт |
| 236 | Погодный эффект | `[тип, сила, длительность, ждать]` |
| 241 / 242 | Играть / остановить BGM | `[{name, volume, pitch, pan}]` |
| 245 / 246 | Играть / остановить BGS | `[{name, volume, pitch, pan}]` |
| 249 | Играть ME | `[{name, volume, pitch, pan}]` |
| 250 | Играть SE | `[{name, volume, pitch, pan}]` |

Оттенок в 223 — это диапазон −255…255 для r/g/b и 0…255 для «серости».
Пещера примерно `[-68, -68, 0, 68]`, закат `[68, -34, -34, 0]`.

## Прочее, что пригождается на картах

| code | Команда | parameters |
|---|---|---|
| 301 | Начать бой | `[тип, troopId, можно сбежать, можно проиграть]` |
| 302 | Открыть магазин | `[тип товара, id, цена, только покупка]` |
| 355 / 655 | Скрипт (первая строка / продолжение) | `["код"]` |
| 356 | Команда плагина (MV) | `["строка"]` |
| 357 | Команда плагина (MZ) | `[плагин, команда, ключ, {аргументы}]` |

Команды плагинов в MV и MZ устроены **по-разному**: в MV это строка (356), в MZ
— структурированные параметры (357). Переносить события между версиями надо
с оглядкой на это.

## Помощники в библиотеке

`Cmd.*` из `scripts/rpgmap.js` собирает всё вышеперечисленное с правильными
параметрами: `text`, `choices`, `when`, `whenCancel`, `endBranch`, `selfSwitch`,
`gameSwitch`, `variable`, `playSE/ME/BGM`, `wait`, `transfer`, `showAnimation`,
`showBalloon`, `changeItems`, `changeGold`, `commonEvent`, `screenTint`,
`moveRoute`, `ifSelfSwitch`. Чего нет — собирается через `Cmd.raw(code, params, indent)`.
